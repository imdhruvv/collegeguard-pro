# CollegeGuard - Smart Campus Management System

A comprehensive college management platform with real-time IoT monitoring, attendance tracking, security alerts, and student wellness monitoring.

## Features

- **Role-Based Access Control** (Admin, Faculty, Student)
- **Real-time Resource Monitoring** (Electricity, Water, WiFi)
- **Smart Attendance System** with QR codes
- **Security Event Tracking** with emergency alerts
- **Student Wellness Surveys** and analytics
- **Advanced Analytics Dashboard**
- **Entry/Exit Logging System**

## Tech Stack

### Backend
- Node.js + Express
- MongoDB with Mongoose
- Socket.IO for real-time updates
- JWT Authentication
- bcryptjs for password hashing
- Nodemailer for email alerts

### Frontend
- React 19
- Material-UI (MUI)
- Recharts for data visualization
- Socket.IO Client
- Axios for API calls
- React Router for navigation
